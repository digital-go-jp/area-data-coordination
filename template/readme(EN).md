# Various Formats
This repository contains tools and formats that can be used by local governments, as well as formats required for surveys conducted by the Digital Agency.

## Data Map
This format serves as an assessment tool during the initial phase of implementing and promoting shared use of the area data coordination platform. It helps local governments and regional businesses identify their current data assets and how they can be effectively utilized. The Data Map provides a standardized framework for systematically organizing and documenting data locations, contents, attributes, connectivity methods, update frequencies, and integration statuses. It is used annually as part of standardized surveys.
