# 標準データモデル
エリアデータ連携基盤における標準データモデルを管理するリポジトリです。

## 概要

本リポジトリは、地域データの連携・相互利用を見据えた**エリアデータ標準データモデル**を格納・管理することを目的としています。

同じ「公共施設」「イベント」「医療機関」等のデータであっても、項目名や値の持ち方が団体・分野ごとに異なると、データの比較・再利用・共有が困難になります。本データモデルは、地域で繰り返し利用されるデータセットを再利用可能な単位で標準化し、データの相互運用性（インターオペラビリティ）とサービスアプリの移植性を確保することを目指します。

## 対象分野

以下の分野の標準データモデルを収録しています。

| 分野 | データモデル |
|------|-------------|
| 行政サービス | 公共施設 / 人口統計・年齢別人口 / 消防水利施設 |
| 住民サービス | ユーザ / 地域ポイント・地域通貨 / 公衆無線LANアクセスポイント / 公衆トイレ / 空き家バンク / 子育て支援施設 |
| 観光・地域活性化 | イベント / 人流データ / 観光施設 / 文化財 |
| 健康・医療 | AED設置場所 / 医療機関 / 介護サービス事業所 |
| 交通・モビリティ | 公共交通運行情報 / 乗降実績データ / 駐車場 / 駐輪場 / シェアサイクルポート |
| 教育 | 学校 |

## 前提条件

- 緯度・経度の座標参照系は、原則として **JGD 2011/(B,L)（日本測地系 2011）** を使用します。
- 「項目必須」欄が必須の項目は、使用しない場合でも削除しないでください（不足項目の追加は可能）。
- 「値必須」欄は、データ入力の必須／任意（NULL許容）を示します。
- 型欄に複数の型が併記されている場合は、利用目的に応じて選択してください。
- 個人情報を含むデータの取扱いは、個人情報保護法その他の関係法令・ガイドラインに従ってください。
