# エリアデータ連携基盤の共同利用ガイドブック 第3.0版

[![発行元](https://img.shields.io/badge/発行元-デジタル庁-0017B6)](https://www.digital.go.jp/)
![発行日](https://img.shields.io/badge/発行日-2026--09--04-lightgrey)

本リポジトリは、デジタル庁が発行する **「エリアデータ連携基盤の共同利用ガイドブック 第3.0版」の本編（構造化テキスト）** を公開するものです。地方公共団体・地域事業者・システムベンダが、エリアデータ連携基盤の**共同利用**と**データ利活用**を検討・実装する際の実務指針として利用いただくことを目的としています。

第3.0版では、AIによる利活用（LLM等による検索・解析のしやすさ）を考慮し、Markdownによる機械判読可能な形式で提供しています。

## 収録内容
第1〜14章で基盤の目的・構成、コスト構造、共同利用の型、検討プロセス、継続的な運用、相互運用性、データ利活用等を扱います。参考1は既存サービスの接続方法、参考2は国の他基盤との関係性を扱います。

## 想定ユースケース
- **DX/政策担当** — 共同利用の必要性整理、予算要求・議会説明資料の作成
- **広域連携の事務局** — 現状の棚卸しと移行計画の立案
- **システムベンダ** — 接続方式（API/データモデル/ID連携）の設計
- **生成AIの活用** — 例：第5章（コスト構造）をLLMに読み込ませ、財政課向け予算要求資料や想定Q&Aのたたき台を作成
