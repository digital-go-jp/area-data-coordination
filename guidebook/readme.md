# エリアデータ連携基盤の共同利用ガイドブック

[![発行元](https://img.shields.io/badge/発行元-デジタル庁-0017B6)](https://www.digital.go.jp/)
![発行日](https://img.shields.io/badge/発行日-2026--09--04-lightgrey)

本リポジトリは、デジタル庁が発行する **「エリアデータ連携基盤の共同利用ガイドブック」** の最新版を公開するものです。地方公共団体・地域事業者・システムベンダが、エリアデータ連携基盤の**共同利用**と**データ利活用**を検討・実装する際の実務指針として利用いただくことを目的としています。

HTMLファイルは、ビジュアルを整え見やすく読みやすいドキュメントとして提供しています。
Markdownファイルは、AI等の活用を想定した機械判読可能な、構造化されたドキュメントとして提供しています。

## 収録内容
第1〜14章で基盤の目的・構成、コスト構造、共同利用の型、検討プロセス、継続的な運用、相互運用性、データ利活用等を扱います。参考1として既存サービスとの接続方法を収録。
