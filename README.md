# エリアデータ連携基盤
本リポジトリは、デジタル庁が示している「エリアデータ連携基盤」に関する様々な資料や、標準データモデルなどを利用いただくことを目的としています。


## エリアデータ連携基盤の共同利用ガイドブック
本ガイドブックは、タイトルにあるとおり、元々はエリアデータ連携基盤の共同利用を目的とした、共同利用ビジョンを作成するためものでした。現在は、エリアデータ連携基盤の共同利用に向けた方針や検討内容だけでなく、その背景、活用事例、エリアデータの利活用について、デジタル庁として考えを網羅した内容に改版しています。

2026年9月4日公開　[第3版](https://github.com/digital-go-jp/area-data-coordination/tree/main/guidebook)


## エリアデータ利活用に向けた標準データモデル
本データモデルは、地域で繰り返し利用されるデータセットを再利用可能な単位で標準化し、エリアデータの相互参照・相互利用を促進を目的とします。標準化されたデータは、オープンデータとしての公開、団体間でのデータ共有、そしてエリアデータ連携基盤等を用いたサービス展開のいずれの場面でも、データ変換の追加負担なく活用できます。

2026年9月4日公開　[初版](datamodels/エリアデータ活用のためのデータモデル（実践ガイドライン）.md)
